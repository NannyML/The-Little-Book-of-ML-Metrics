\chapteropener{Regression}{cyanlight}{cyanaccent}{%
Regression models predict numerical values, such as a house price or a delivery time. To evaluate them, we compare each prediction with the actual value. If a delivery takes $40$ minutes after the model predicted $30$, the prediction was $10$ minutes too low. To judge the model over many deliveries, we need a way to summarize these individual errors.

How we combine the errors changes what the score tells us. Averaging their absolute sizes gives us an error in minutes, while squaring them before averaging gives large misses more weight. We can also express errors as percentages to understand their size relative to the values we are predicting.

This chapter explains these ways of measuring error and when each is useful. We also look at how to compare a model with a simple baseline, such as always predicting the average delivery time from past data, and at measures for tasks such as predicting counts or the direction of change.}{In this chapter}

% ---------- MAE ----------
\clearpage
\thispagestyle{regressionstyle}
\section{MAE}\label{sec:mae}
\subsection{Mean Absolute Error}

MAE is one of the most intuitive regression metrics: it tells you, on average, how far off your predictions are in the same units as your target. If you're predicting house prices and your MAE is $\$15{,}000$, your predictions are off by $\$15{,}000$ on average. This directness makes MAE a useful metric when you need to communicate model performance to non-technical stakeholders.

% equation
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                MAE = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^n |{\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t}|
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-0.4,0.2)$) to[bend left=15] node[pos=1, left] {number of samples} +(-1,-.5);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.2,-0.3)$) to[bend left=15] node[pos=1, right] {forecast value} +(1,.5); 
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.2,0.5)$) to[bend right=15] node[pos=1, right] {actual value} +(1,-.5);
    }
\end{center}

MAE ranges from $0$ (perfect) to $+\infty$. To interpret it in context, compare it with the MAE of always predicting the training data's mean target value. A much lower MAE on the same test data means your model improves on that simple baseline; a similar MAE means it performs much the same.

\textbf{When to use MAE?}

Use MAE when each extra unit of error matters equally and overprediction has the same cost as an equally large underprediction. It can serve as both a training loss and an evaluation metric. If large misses deserve extra weight, consider squared error instead.

% strength and weakness box
\coloredboxes{
    \item Less sensitive to large misses than MSE. If $99$ errors have size $1$ and one has size $100$, MAE is $1.99$ while RMSE is about $10$. A sufficiently large miss can still dominate MAE.
    \item Directly interpretable. MAE = $5.2$ means ``on average, predictions miss by $5.2$ units.'' No square roots or percentage conversions needed.
}
{
    \item Hides the spread of error sizes. Many small misses can produce the same MAE as fewer large ones; inspect the individual errors when this distinction matters.
    \item Has a sharp corner at zero, but gradient-based methods can still optimize it using subgradients. Huber loss offers a smooth transition for small errors.
}

\orangebox{Did you know that...}
{Minimizing MAE leads to predicting the \textbf{median}, while minimizing MSE leads to predicting the \textbf{mean}.
This is why MAE is more robust to outliers --- the median is less affected by extreme values than the mean. If your target distribution
is skewed (e.g., income, claim amounts), this distinction matters: MAE and MSE will favor different models.}

\textbf{Other related metrics}

RMSE gives larger errors more weight. When MAE is nonzero, an RMSE/MAE ratio near $1$ means the absolute error sizes are similar; a larger ratio indicates more variation in their sizes. Percentage measures offer another perspective when the target has a meaningful zero.

% ---------- MSE ----------
\clearpage
\thispagestyle{regressionstyle}
\section{MSE}\label{sec:mse}
\subsection{Mean Squared Error}

Mean Squared Error (MSE) averages the squares of the prediction errors. Squaring gives large misses more weight: an error of $10$ contributes $100$ to the sum, while an error of $1$ contributes only $1$. Both overpredictions and underpredictions contribute positively, so they cannot cancel each other out.

% equation
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                MSE = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^n \left({\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t}\right)^2
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-0.70,0.25)$) to[bend left=15] node[pos=1, left] {number of samples} +(-1.00,-0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.05,-0.30)$) to[bend left=15] node[pos=1, right] {forecast value} +(1.00,0.50); 
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.00,0.55)$) to[bend right=15] node[pos=1, right] {actual value} +(1.00,-0.50);
    }
\end{center}

MSE ranges from 0 (perfect) to $+\infty$. The main interpretation challenge is that MSE is in squared units — if you're predicting
revenue in dollars, MSE is in dollars-squared. Take the square root to get RMSE, which returns to interpretable units.

\textbf{When to use MSE?}

Use MSE when a few large misses should matter more than many small ones. It is also a common training loss. Before choosing it, consider whether extreme errors represent important failures or faulty data: the metric will give them substantial weight either way.

% strength and weakness box
\coloredboxes{
    \item Smooth as a function of the prediction, which makes it convenient for gradient-based training.
    \item Matches a quadratic error cost: if a mistake twice as large costs four times as much, squared error reflects that relationship.
}
{
    \item A single large error can dominate. One prediction off by $100$ contributes as much as $10{,}000$ predictions off by $1$. Inspect the error distribution to see what drives the score.
    \item Units are squared (dollars$^2$, meters$^2$), making raw MSE values hard to interpret. Report RMSE instead when communicating results.
}

{Expected squared prediction error combines three sources: systematic error (squared bias), variation between models fitted on different training samples, and noise in the outcomes that the inputs cannot explain. Two learning methods can have the same expected MSE for different reasons. A single test score does not tell us how much each source contributes.}

\textbf{Other related metrics}

RMSE is the square root of MSE, so it returns the score to the target's units. The two rank models identically on the same evaluation data. MAE gives less emphasis to large misses, while inspecting individual errors shows which predictions drive the difference.

\clearpage
\thispagestyle{regressionstyle}
\section{MSLE}\label{sec:msle}
\subsection{Mean Squared Log Error}

MSLE measures prediction errors on a logarithmic scale. We add one to each actual and predicted value, take their natural logarithms, then average the squared differences. Predicting $110$ instead of $100$ gives approximately the same penalty as predicting $1100$ instead of $1000$. Both are $10\%$ over-predictions; the added one makes their penalties slightly different.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                MSLE = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^n \left(log({\color{nmlcyan}Y_t} + 1) - log({\color{nmlpurple}\hat{Y}_t} + 1)\right)^2
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-2.40,0.30)$) to[bend left=15] node[pos=1, left,align=center] {number\\of samples} +(-1.00,-0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(3.05,-0.35)$) to[bend left=15] node[pos=1, right] {forecast value} +(1.00,0.50); 
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(0.10,0.60)$) to[bend right=15] node[pos=1, right] {actual value} +(1.00,-0.50);
        }
\end{center}

MSLE is $0$ for perfect predictions and has no upper bound. For a fixed actual value, it penalizes an under-prediction more than an equally large over-prediction. If the actual is $100$, predicting $50$ contributes more loss than predicting $150$.

\textbf{When to use MSLE?}

Use MSLE for nonnegative quantities spanning a wide range, such as website traffic or prices, when proportional differences matter more than differences in the original units. Its unequal penalties for under- and over-prediction do not automatically represent business costs; specify those costs separately when they matter.

% strength and weakness box
\coloredboxes{
    \item Similar proportional errors give similar penalties when values are large relative to one, so large targets do not dominate merely because of their size.
    \item Adding one allows zero actuals and zero predictions to enter the calculation.
}
{
    \item The added one matters near zero, so changing measurement units can change the score. MSLE is not exactly scale-invariant.
    \item This book uses MSLE for nonnegative actuals and predictions. For equally sized raw errors to receive equal penalties in either direction, use MAE or MSE.
}

{MSLE is MSE applied to a specific transformation: $MSLE = MSE(\log(Y+1), \log(\hat{Y}+1))$. To train this way, use $\log(1+Y)$ as the target and MSE as the loss. Convert each predicted log value back by exponentiating it and subtracting one. Using $\log(Y)$ instead would optimize a different loss.}

\textbf{Other related metrics}

Related metrics for MSLE include Mean Absolute Log Error (MALE) and Root Mean Squared Log Error (RMSLE).

\clearpage
\thispagestyle{regressionstyle}
\section{RMSE}\label{sec:rmse}
\subsection{Root Mean Squared Error}

RMSE is the square root of the average squared prediction error. Taking the root returns the score to the target's units: for temperatures measured in °C, an RMSE of $2.3$ is also measured in °C. Large misses pull the score upward because we square the errors before averaging them.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                RMSE = \sqrt{\frac{1}{{\color{nmlred}n}} \sum_{t=1}^n \left({\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t}\right)^2}
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-0.20,0.35)$) to[bend left=20] node[pos=1, left] {number of samples} +(-1.00,-0.70);
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.50,0.70)$) to[bend right=15] node[pos=1, right] {actual value} +(1.00,-0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.50,-0.55)$) to[bend left=30] node[pos=1, right] {forecast value} +(1.00,0.20); 
    }
\end{center}

RMSE is nonnegative and is always at least MAE. They are equal when all errors have the same absolute size: errors of $-2$ and $+2$ give both scores of $2$. When MAE is positive, the ratio RMSE/MAE lies between $1$ and $\sqrt{n}$. A ratio near $1$ means similar error sizes; a larger ratio shows more variation relative to the average size. For perfect predictions, both scores are zero and the ratio is undefined.

\textbf{When to use RMSE?}

Use RMSE when large errors deserve extra weight but you want to report the result in the target's units. Compare models on the same evaluation data. Across targets with different scales, choose a normalization or baseline that makes sense for the task rather than comparing raw RMSE values.

% strength and weakness box
\coloredboxes{
    \item Expresses squared-error performance in the target's units rather than squared units.
    \item Ranks models exactly as MSE does on the same data, preserving its emphasis on large errors.
}
{
    \item Depends on the target's scale. Any normalized version needs an explicit, meaningful denominator.
    \item Can be much larger than most errors. One miss of $100$ among $99$ misses of $1$ gives RMSE about $10.0$, although MAE is only $1.99$.
}

\section{RMSLE}\label{sec:rmsle}
\subsection{Root Mean Squared Log Error}

RMSLE measures prediction errors on a logarithmic scale, using the square root of MSLE. We add one to actual and predicted values, take their logarithms, and calculate RMSE from those transformed values. This emphasizes proportional differences while returning the score in log units rather than squared log units.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                RMSLE = \sqrt{\frac{1}{{\color{nmlred}n}} 
                        \sum_{t=1}^n
                        \left(
                            {log{({\color{nmlcyan}Y_t} + 1)}} -
                            {log{({\color{nmlpurple}\hat{Y}_t} + 1)}}
                        \right)^2}
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-1.90,0.45)$) to[bend right=15] node[pos=1, right] {number of samples} +(1.00,-0.80);
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(0.60,0.70)$) to[bend right=15] node[pos=1, right] {actual value} +(1.00,-0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(3.50,-0.60)$) to[bend left=20] node[pos=1, right] {forecast value} +(0.40,0.90); 
    }
\end{center}

RMSLE is $0$ for perfect predictions and has no upper bound. For one prediction, an absolute log difference of $0.1$ means the larger shifted value is about $1.105$ times the smaller. RMSLE summarizes many such differences, giving extra weight to large ones; it is not an average percentage error.

\textbf{When to use RMSLE?}

Use RMSLE for nonnegative prices or counts when proportional differences matter more than differences in the original units. The added one makes proportional comparisons approximate, particularly near zero. Use RMSE or MAE on the original scale when equally sized over- and under-predictions should receive equal penalties.

% strength and weakness box
\coloredboxes{
    \item Predicting $110$ instead of $100$ and $1100$ instead of $1000$ gives nearly equal log errors, rather than letting the larger raw miss dominate.
    \item Taking the root changes the reported scale while preserving every MSLE model ranking.
}
{
    \item Here, actuals and predictions must be nonnegative. The added one permits zeros but means changing units can change the score.
    \item Its larger penalty for under-prediction need not match the cost of a shortfall. RMSLE is already RMSE on $\log(1+Y)$; that transformation does not remove the asymmetry in raw errors.
}

\thispagestyle{regressionstyle}
\section{MAPE}\label{sec:mape}
\subsection{Mean Absolute Percentage Error}

MAPE is the average absolute prediction error expressed as a percentage of each actual value. A MAPE of $5\%$ means predictions are $5\%$ off on average, without distinguishing over- from under-predictions. This makes errors easier to compare across quantities of different sizes, provided a percentage has a meaningful interpretation.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                MAPE = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^n \left| \frac{Y_t - \color{nmlpurple}\hat{Y}_t}{\color{nmlcyan}Y_t} \right| \times 100
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-0.95,0.30)$) to[bend left=15] node[pos=1, left] {number of samples} +(-1.00,-0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(1.65,-0.05)$) to[bend left=15] node[pos=1, right] {forecast value} +(1.00,0.50); 
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.15,0.20)$) to[bend right=15] node[pos=1, right] {actual value} +(1.00,-0.50);
    }
\end{center}

MAPE is $0\%$ for perfect predictions and has no upper bound. Judge it against a relevant baseline on the same task and forecast horizon. A score that is useful for one forecasting problem may be unacceptable for another.

\textbf{When to use MAPE?}

Use MAPE for quantities with a meaningful zero, such as positive sales volumes, when relative error is the quantity you want to report. With actual sales of $100$, predictions of $90$ and $110$ both contribute $10\%$. The weighting changes across actual values: the same absolute miss counts more when the actual is smaller.

% strength and weakness box
\coloredboxes{
    \item Unchanged when actuals and forecasts are multiplied by the same positive conversion factor, such as dollars to cents.
    \item Percentage errors are often easy to communicate when the target has a meaningful zero.
}
{
    \item Undefined when an actual value is zero. Small nonzero actuals can produce enormous but finite percentage errors.
    \item Gives more weight to small actuals for the same absolute miss. Minimizing it can favor lower forecasts; it does not target the mean outcome.
}

\textbf{Other related metrics}

sMAPE uses both actual and predicted values in its denominator. wMAPE divides total absolute error by total absolute actuals, while MASE scales errors by a historical naive-forecast error. The latter two can handle individual zero actuals, provided their overall denominators are nonzero.

\clearpage
\thispagestyle{regressionstyle}
\section{sMAPE}\label{sec:smape}
\subsection{Symmetric Mean Absolute Percentage Error}

sMAPE averages percentage errors using the sizes of both the actual and predicted values. It divides each absolute error by the average of those two absolute values. The name ``symmetric'' refers to swapping actual and prediction: doing so leaves the score unchanged.

% formula
\vspace{0.5em}
\begin{center}
	\tikz{
		\node[inner sep=2pt, font=\Large] (a) {
			{
				$\displaystyle
				sMAPE = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^n \frac{\left| {\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t} \right|}{({|\color{nmlcyan}Y_t}| + {|\color{nmlpurple}\hat{Y}_t}|)/2} \times 100
				$
			}
		};
		\draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-1.35,0.30)$) to[bend left=15] node[pos=1, left] {number of samples} +(-1.00,-0.50);
		\draw[overlay,-latex,nmlcyan, semithick] ($(a.north)+(0.70,-0.10)$) to[bend right=15] node[pos=1, left] {actual value} +(-1.00,0.50);
		\draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(1.75,-0.10)$) to[bend left=15] node[pos=1, right] {forecast value} +(1.00,0.50);
	}
\end{center}

The convention shown here ranges from $0\%$ to $200\%$, with $0\%$ for perfect predictions. Some implementations omit the factor of two and report half these values. Neither convention gives equal penalties to equally sized misses around a fixed actual: if the actual is $100$, predicting $90$ gives about $10.5\%$, while predicting $110$ gives about $9.5\%$ under this formula.

\textbf{When to use sMAPE?}

Use sMAPE when you want a bounded percentage measure that considers both actual and forecast size. It has been used in the M3 and M4 forecasting competitions. Check its behavior near zero before choosing it: a bounded score can still hide meaningful differences between forecasts.

% strength and weakness box
\coloredboxes{
    \item Each defined contribution is bounded by $200\%$, so a very small actual cannot produce an arbitrarily large percentage.
    \item Treats an actual--prediction pair the same way when the two values are exchanged.
}
{
    \item With an actual of zero, every nonzero forecast scores $200\%$, whether it is $0.01$ or $100$. The score cannot distinguish their error sizes.
    \item Two zeros give $0/0$ and need an explicit convention, often a zero contribution. Tiny changes near zero can still cause large percentage changes.
}

{The geometric mean need not minimize sMAPE. For positive $x$, $y$ and $z$, consider this error sum without its constant scale factor:
\[
s(x,z)+s(y,z) = \frac{|x - z|}{x + z} + \frac{|y - z|}{y + z}
\]
The geometric mean gives the candidate:
\[
z = \sqrt{x \cdot y}
\]
For $x=100$ and $y=400$, this gives $z=200$ and error $2/3$. Choosing $z=100$ gives $0.6$, so the geometric mean does not minimize this error.}

\textbf{Other related metrics}

\section{wMAPE}\label{sec:wmape}
\subsection{Weighted Mean Absolute Percentage Error}

wMAPE measures total absolute prediction error as a percentage of the sum of absolute actual values. It adds the errors before dividing, so individual zero actuals do not make the score undefined. When forecasting sales revenue, for example, a larger channel contributes more than a smaller one if their percentage errors are the same.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                wMAPE = \frac{\sum_{t=1}^n |{\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t}|}{\sum_{t=1}^n |{\color{nmlcyan}Y_t}|} \times 100
                $
            }
        };
        \draw[overlay,-latex,nmlcyan,semithick] ($(a.north)+(0.80,-0.15)$) to[bend right=15] node[pos=1, left] {actual value} +(-1.00,0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(1.85,0.00)$) to[bend left=15] node[pos=1, right] {forecast value} +(1.00,0.50); 
    }
\end{center}

wMAPE ranges from $0\%$ to $+\infty$ and is undefined when all actuals are zero. A score of $8\%$ means total absolute error is $8\%$ of the total absolute actuals; it does not mean every prediction misses by $8\%$.

\textbf{When to use wMAPE?}

Use wMAPE when you want a percentage summary that allows some actuals to be zero and gives more weight to larger actual values. This can suit sales or demand forecasts. The weights follow the target: revenue forecasts are weighted by revenue, but unit-demand forecasts do not account for prices or margins.

% strength and weakness box
\enlargethispage{2\baselineskip}
\coloredboxes{
    \item Individual zeros still contribute their absolute forecast errors to the numerator. Only a zero total in the denominator prevents calculation.
    \item On one dataset, wMAPE and MAE rank models identically. The percentage makes the total error easier to compare with the amount being forecast.
}
{
    \item Large actuals receive more weight than small ones. Good predictions for a large product can hide large percentage errors on smaller products.
    \item Target size is not the same as business importance. If margins or the costs of mistakes differ, evaluate those consequences separately.
}

\begin{center}
    \includegraphics[width=\textwidth]{figures/wMAPE_compare_MAPE.png}
\end{center}

\textbf{Figure. wMAPE.} Four sales channels of one forecast. \underline{Left:} MAPE per channel; every channel is about $10\%$ off and the mean is $9.9\%$. \underline{Right:} bar width shows each channel's contribution to wMAPE: its absolute error divided by total revenue. \orangebox{Did you know that...}
{wMAPE is also called WAPE. It equals MAE divided by the mean absolute actual value, multiplied by $100$. With no zero actuals, it is also a weighted average of percentage errors, with weights proportional to actual size. But zero rows must not be discarded: actuals $[100,0]$ and forecasts $[90,10]$ give $20\%$, because both errors enter the numerator.}

\textbf{Other related metrics}

MAPE weights each percentage error equally, while wMAPE gives larger actuals more weight. If MAPE is higher, small actuals may have larger percentage errors; inspect the individual contributions before drawing a conclusion. For time series, MASE instead scales errors by a naive forecast's error on the training history.

\section{MASE}\label{sec:mase}
\subsection{Mean Absolute Scaled Error}

MASE measures forecast errors relative to the error of a simple forecast on the training history. For a nonseasonal series, that simple forecast repeats the previous value. We calculate its average absolute error on the historical data, then divide the model's evaluation MAE by that amount. This puts errors from series with different units on a common scale.

% formula
\vspace{0.5em}
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                MASE = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^n \frac{|{\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t}|}{\frac{1}{n-1} \sum_{t=2}^n |{\color{nmlcyan}Y_t} - {\color{nmlcyan}Y_{t-1}}|}
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-1.50,0.25)$) to[bend left=15] node[pos=1, left] {number of samples} +(-1.00,-0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.30,0.00)$) to[bend left=15] node[pos=1, right] {forecast value} +(1.00,0.50);
        \draw[overlay,-latex,nmlcyan,semithick] ($(a.north)+(1.25,-0.15)$) to[bend right=15] node[pos=1, left] {actual value} +(-1.00,0.50);
    }
\end{center}
\vspace{0.5em}

The formula illustrates both averages on one series. For future forecasts, keep the denominator fixed from the training history. MASE $=0.6$ means the model's MAE is $40\%$ below that historical scale; it does not establish that the model beats a naive forecast on the same future period.

\textbf{When to use MASE?}

Use MASE to compare forecast errors across time series with different scales. It allows individual zero actuals, including periods with no demand, provided the historical scaling error is positive. For seasonal data, use a seasonal naive forecast that repeats the value from the previous season.

% strength and weakness box
\coloredboxes{
    \item Avoids dividing by each actual value, so an individual zero does not make the score undefined.
    \item Uses the same historical error scale for models evaluated on one series, making their errors comparable without the target's units.
}
{
    \item The denominator can be zero. A constant training series gives a lag-one naive forecast no error, so MASE cannot be calculated.
    \item The historical scale may not represent the future. To check whether a model beats the naive forecast in deployment, compare both on the same evaluation dates.
}

\thispagestyle{customstyle}

\begin{center}
    \includegraphics[width=\textwidth]{figures/MASE_naive_baseline.png}
\end{center}

\textbf{Figure. MASE.} \underline{Top:} forty days of demand, the model's forecast and the naive forecast that repeats yesterday's value. \underline{Bottom:} their absolute errors, with the means dashed. Scaling by historical naive errors also avoids MAPE's division by individual actual values. Their paper explicitly notes an exception: a constant history leaves MASE with a zero denominator.}

\textbf{Other related metrics}

MAPE and sMAPE express errors relative to actuals or predictions; MASE uses a historical forecast error instead. RMSE gives larger misses more influence than MAE. For direction rather than magnitude, consider MDA.

\section{MDA}\label{sec:mda}
\subsection{Mean Directional Accuracy}

MDA measures how often a forecast gets the direction of a change right. A stock-price forecast can miss tomorrow's price but still correctly predict whether it will rise or fall. MDA compares the actual and forecast changes with the last observed value, counting how often their directions match.

% formula
\vspace{0.5em}
\begin{center}
    \tikz{
    \node[inner sep=2pt, font=\Large] (a) {
        {
            $\displaystyle
            MDA = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^{n} {\color{nmlgreen}\mathds{1}}_{{\color{nmlyellow}sign}({\color{nmlcyan}y_t} - {\color{nmlcyan}y_{t-1}}) == {\color{nmlyellow}sign}({\color{nmlpurple}\hat{y}_t} - {\color{nmlcyan}y_{t-1}})}
            $
        }
    };

    % Draw arrows for annotations
    \draw[overlay,-latex, nmlred, semithick] ($(a.south)+(-2.05,0.30)$) to[bend left=15] node[pos=1, left,align=center] {number \\ of samples} +(-1.00,-0.50);
    \draw[overlay,-latex,nmlcyan,semithick] ($(a.north)+(0.70,-0.65)$) to[bend right=27] node[pos=1, left] {actual value} +(-0.60,0.85);
    \draw[overlay,-latex, nmlpurple, semithick] ($(a.north)+(3.00,-0.70)$) to[bend left=15] node[pos=1, right,align=center] {forecast\\value} +(1.00,0.50);
    \draw[overlay,-latex, nmlgreen, semithick] ($(a.west)+(3.65,-0.20)$) to[bend right=37] node[pos=1, right] {indicator} +(0.75,-0.60);
    \draw[overlay,-latex, nmlyellow, semithick] ($(a.south)+(2.60,0.50)$) to[bend right=15] node[pos=1, right] {sign function} +(1.00,-0.50);
    }
\end{center}
\vspace{0.5em}

MDA ranges from $0$ to $1$: a score of $0.6$ means $60\%$ of directions were correct. A fair coin has expected accuracy $0.5$ on up-or-down outcomes, but this is not always a useful benchmark. If prices rose on $80\%$ of days, always predicting ``up'' would score $0.8$.

\textbf{When to use MDA?}

Use MDA when the direction of change matters, such as in stock or energy-price forecasting. Compare with a simple directional baseline on the same period. When the size of a change also matters, examine the errors or decision outcomes alongside the hit rate.

% strength and weakness box
\coloredboxes{
    \item Independent of units and move size. Forecasts of ``up by $\$1$'' and ``up by $\$100$'' both count as correct if the price rises.
    \item Easy to interpret as the fraction of directions predicted correctly.
}
{
    \item A small missed move and a large missed move count equally. A high hit rate does not establish that a trading strategy is profitable.
    \item Small fluctuations can flip a direction. Under the sign function shown here, a zero change matches only a forecast of no change.
}

\end{center}

MAE and RMSE assess error magnitude, while MASE compares it with a historical error scale. These complement MDA when evaluating forecasts, but a trading strategy also needs evaluation of its actual gains, losses, and costs.

\section{MPD}\label{sec:mpd}
\subsection{Mean Poisson Deviance}

MPD measures errors in predictions of an expected count. For example, a model might predict an average of $12$ calls for days with similar conditions, while one such day receives $10$. MPD uses the observed and predicted counts in a loss derived from a Poisson probability model, then averages that loss across observations.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                \text{MPD} = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^{n} 2 \left( {\color{nmlcyan}Y_t} \log \left( \frac{{\color{nmlcyan}Y_t}}{{\color{nmlpurple}\hat{Y}_t}} \right) - ( {\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t} ) \right)
                $
            }
        };
        \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-2.70,0.25)$) to[bend left=15] node[pos=1, left,align=center] {number\\of samples} +(-1.00,-0.50);
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.north)+(1.10,-0.10)$) to[bend left=15] node[pos=1, right] {actual value} +(1.00,0.50);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.south)+(1.10,0.15)$) to[bend right=15] node[pos=1, right] {predicted value} +(1.00,-0.50);
    }
\end{center}

MPD ranges from $0$ to $+\infty$, with lower values indicating smaller loss. Compare models with a suitable baseline on the same data, such as the training mean count. Zero actuals are valid: their contribution is twice the predicted count, using the standard limit for the logarithmic term.

\textbf{When to use MPD?}

Use MPD to assess predictions of mean counts or rates, such as calls per day or claims per year. A Poisson model assumes equal mean and variance among cases with the same inputs, but exact Poisson outcomes are not required to calculate the score. Many zero outcomes alone do not require a different loss.

% strength and weakness box
\coloredboxes{
    \item Reflects count size. $\text{MPD}(100,150)\approx18.907$, while $\text{MPD}(1,1.5)\approx0.189$. Multiplying both values by $100$ multiplies the loss by $100$.
    \item Shares the data-fit objective of Poisson regression. Training may also include a regularization penalty.
}
{
    \item Actuals must be nonnegative and predictions strictly positive. A log link ensures positive predictions; replacing zeros with a small floor changes the score.
    \item Its penalty does not specify the cost of a missed count or an excess prediction. Use an explicit cost measure when those consequences are the evaluation goal.
}

\clearpage
\thispagestyle{customstyle}

\begin{figure*}[ht!]
    \centering
    \includegraphics[width=0.6\textwidth]{figures/MPD_cross_section.png}
\end{figure*}

\textbf{Figure. MPD.} The loss for one observation with $Y=10$, as the prediction changes. The smooth curve is asymmetric: predicting $5$ incurs more deviance than predicting $15$, although both miss by five. This describes the loss's behavior; whether underprediction is more costly depends on the application.

\orangebox{Did you know that...}
{A saturated Poisson model assigns each observation its own mean and fits every count exactly. MPD is twice its log-likelihood advantage over the fitted model, divided by the number of observations. Minimizing this loss therefore gives the unregularized Poisson maximum-likelihood fit. \texttt{PoissonRegressor} uses this data-fit loss but normally adds a regularization penalty.}

\textbf{Other related metrics}

MPD and MGD are members of the Tweedie deviance family. The compound Poisson--Gamma model, with $1<p<2$, describes a mix of zero and positive continuous amounts, such as total claim cost; it is not a general replacement for counts with many zeros. If MPD and MAE rank models differently, inspect the cases contributing most to each loss before deciding why.

\section{MGD}\label{sec:mgd}
\subsection{Mean Gamma Deviance}

MGD measures errors in predictions of a positive mean, using the ratio between each observed and predicted value. A prediction that is half the actual value receives the same penalty whether the actual is $100$ or $1{,}000$. The loss comes from a Gamma probability model and is commonly used for positive amounts such as insurance claim severity.

% formula
\begin{center}
    \tikz{
    \node[inner sep=2pt, font=\Large] (a) {
        {
            $\displaystyle
            \text{MGD} = \frac{1}{{\color{nmlred}n}} \sum_{t=1}^{n} 2 \left( \log\left(\frac{{\color{nmlpurple}\hat{y}_t}}{{\color{nmlcyan}y_t}}\right) + \frac{{\color{nmlcyan}y_t}}{{\color{nmlpurple}\hat{y}_t}} - 1 \right)
            $
        }
    };
    
    \draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-2.10,0.30)$) to[bend left=15] node[pos=1, left,align=center] {number\\of samples} +(-1.00,-0.50);
    \draw[overlay,-latex, nmlcyan, semithick] ($(a.south)+(1.15,0.20)$) to[bend right=16] node[pos=1, right] {actual value} +(1.00,-0.50);
    \draw[overlay,-latex, nmlpurple, semithick] ($(a.north)+(1.15,-0.10)$) to[bend left=16] node[pos=1, right] {predicted value} +(1.00,0.50);
}
\end{center}

MGD ranges from $0$ to $+\infty$, with $0$ when every prediction equals its actual value. Both actuals and predictions must be strictly positive. Compare models on the same observations and in the context of a suitable baseline.

\textbf{When to use MGD?}

Use MGD when proportional errors matter for positive quantities, such as claim sizes or repair costs. A Gamma model assumes variance proportional to the squared mean among cases with the same inputs. That can motivate the loss, but a skewed target histogram alone does not establish the assumption.

% strength and weakness box
\coloredboxes{
    \item Gives the same penalty to the same prediction-to-target ratio: $MGD(100,150)=MGD(1,1.5)$.
    \item Converting all actuals and predictions to another unit leaves the score unchanged, so the comparison does not depend on dollars versus cents.
}
{
    \item Cannot score zero or negative actuals or predictions. For a mix of zero and positive amounts, a compound Poisson--Gamma model may be appropriate.
    \item Penalizes underprediction more than overprediction for equally sized misses. This fixed asymmetry may not match the costs of a particular decision.
}

\clearpage
\thispagestyle{customstyle}

\begin{figure*}[ht!]
    \centering
    \includegraphics[width=0.6\textwidth]{figures/MGD_cross_section.png}
\end{figure*}

\textbf{Figure. MGD.} The loss for one observation with $Y=10$, as the prediction changes. The minimum is at $\hat{Y}=10$. Predicting half the actual value ($\hat{Y}=5$) incurs about $1.6$ times the loss of predicting double ($\hat{Y}=20$). MGD depends on the ratio $\hat{Y}/Y$, so rescaling both values preserves these penalties.

\orangebox{Did you know that...}
{MGD is scale-invariant: multiplying all actuals and existing predictions by a positive constant leaves the score unchanged. Converting dollars to cents therefore preserves MGD, while MAE, MSE, MPD, and RMSE all change. This makes it useful when the same relative miss should count equally across different-sized amounts.}

\textbf{Other related metrics}

MGD compares ratios, while RMSE gives more weight to large errors in the target's units. If they rank models differently, consider which errors matter for the prediction task. MPD instead scales with count size. Both losses can evaluate mean predictions, even when the full outcome distribution does not follow their namesake probability model exactly.

\section{R-squared}\label{sec:r-squared}
\subsection{R-squared}

R-squared measures how much a model reduces squared prediction error compared with always predicting the mean of the evaluated targets. An $R^2$ of $0.85$ means the model makes $85\%$ less squared error than that baseline. The remaining $15\%$ tells us how much error remains relative to the baseline, but not what caused it.

\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                R^2 = 1 - \frac{\sum_{t=1}^n (Y_t - {\color{nmlpurple}\hat{Y}_t})^2}{\sum_{t=1}^n ({\color{nmlcyan}Y_t} - {\color{teal!70!green}\bar{Y}})^2}
                $
            }
        };
        
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.05,0.00)$) to[bend left=15] node[pos=1, right] {predicted value} +(1.00,0.50); 
        \draw[overlay,-latex,teal!70!green, semithick] ($(a.south)+(2.00,0.10)$) to[bend right=15] node[pos=1, right] {mean of targets} +(1.00,-0.50); 
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.00,0.10)$) to[bend left=15] node[pos=1, left] {target value} +(-1.00,-0.50); 
    }
\end{center}

For nonconstant targets, $R^2=1$ is perfect and $R^2=0$ matches the mean baseline. A negative score means the model has more squared error than that baseline on these data. It does not, by itself, show that performance has deteriorated over time.

\textbf{When to use R-squared?}

Use $R^2$ to express squared error relative to the variation in the targets. It has no units, but scores on different datasets depend on their target variation and difficulty. Pair it with RMSE or MAE to understand error sizes, and inspect large misses that an overall score may hide.

\enlargethispage{\baselineskip}
\coloredboxes{
    \item Changing units, such as meters to centimeters, leaves $R^2$ unchanged when both targets and predictions are rescaled.
    \item The baseline is explicit: $R^2=0$ matches the squared error of predicting the evaluated targets' mean. Using that mean to compute the score is not training leakage.
}
{
    \item In ordinary least-squares regression, adding predictors cannot lower training $R^2$ when the model is refitted on the same data. It need not improve predictions on new data.
    \item When all targets are equal, the denominator is zero. The displayed expression is undefined; software may replace the result with a finite value.
}


\clearpage
\thispagestyle{customstyle}

\begin{center}
    \includegraphics[width=\textwidth]{figures/R2_explained.png}
\end{center}

\textbf{Figure. R² as a ratio of squared-error areas.} On the left, each purple square has side length $|y_i-\hat{y}_i|$, so its area represents one squared prediction error. On the right, the red squares represent errors against the mean baseline. The labeled totals give $R^2=1-3.4/43.2\approx0.92$. If the model's total squared error exceeds the baseline's, $R^2$ is negative.

\orangebox{Did you know that...}
{$R^2=1-MSE_{model}/MSE_{baseline}$, where the baseline predicts the evaluated targets' mean. On the same nonconstant targets, the baseline error stays fixed, so minimizing MSE and maximizing $R^2$ rank models identically. An increase of $0.01$ in $R^2$ corresponds to a decrease of $0.01\times MSE_{baseline}$ in MSE. This equivalence does not make scores from different datasets directly comparable.}

\textbf{Other related metrics}

Adjusted $R^2$ penalizes additional predictors in linear regression, but it does not replace evaluation on held-out data. A large training--test gap can prompt an investigation of overfitting or differences between datasets. D2 Absolute Score uses absolute errors and a median baseline instead.

\thispagestyle{regressionstyle}
\section{D2}\label{sec:d2}
\subsection{D2 Absolute Score}

D2 Absolute Score measures how much a model reduces absolute prediction error compared with always predicting the median of the evaluated targets. It gives each additional unit of error the same weight, whereas R-squared squares errors. A score of $0.46$ means $46\%$ less absolute error than the median baseline.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                D^2_{abs} = 1 - \frac{\sum_{t=1}^n \lvert {\color{nmlcyan}Y_t} - {\color{nmlpurple}\hat{Y}_t}\rvert}{\sum_{t=1}^n \lvert{\color{nmlcyan}Y_t} - {\color{teal!70!green}\tilde{Y}}\rvert}
                $
            }
        };
        
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.30,0.00)$) to[bend left=15] node[pos=1, right] {predicted value} +(1.00,0.50); 
        \draw[overlay,-latex,teal!70!green, semithick] ($(a.south)+(2.30,0.10)$) to[bend right=15] node[pos=1, right] {median of targets} +(1.00,-0.50);
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.20,0.10)$) to[bend left=15] node[pos=1, left] {target value} +(-1.00,-0.50); 
    }
\end{center}

Here $\tilde{Y}$ is the median of the evaluated targets. With a nonzero baseline error, $D^2=1$ means perfect predictions and $D^2=0$ matches the error of always predicting that median. A negative score means the model makes more absolute error than this baseline.

\textbf{When to use D2?}

Use D2 when absolute error fits your task and you want to compare it with a constant baseline. It gives large misses less weight than R-squared does, but an extreme observation can still change both the model's error and the baseline's error substantially.

\coloredboxes{
    \item It expresses absolute error relative to a clear reference. The median minimizes the total absolute error among constant predictions.
    \item Like $R^2$, D2 has no units. Rescaling targets and predictions together leaves the score unchanged.
}
{
    \item On the same targets, missing by $10$ once and making $99$ perfect predictions scores the same as missing by $0.1$ on all $100$. Check large misses separately if they matter.
    \item Constant targets give zero baseline error, making the displayed ratio undefined. Small baseline errors can also make the score sensitive to modest prediction errors.
}

\textbf{Other related metrics}

R-squared uses squared errors and a mean baseline, so it need not agree with D2 even without outliers. If they rank models differently, inspect the errors and decide which penalty fits the task. Both scores use baselines calculated from the evaluated targets by definition. Comparing with a historical training-set baseline is a different skill score.

\clearpage
\thispagestyle{regressionstyle}
\section{Pinball Loss}\label{sec:pinball-loss}
\subsection{Pinball Loss}

Pinball Loss measures the error of a quantile prediction. For example, a predicted $90$th-percentile price of $\$60$ means we expect $90\%$ of prices under those conditions to be at or below $\$60$. This is still a single predicted value, but it targets an upper quantile rather than the mean. Pinball Loss gives under-predictions and over-predictions different weights to target that quantile.

% formula
\begin{center}
    \tikz{
		\node[inner sep=2pt, font=\Large] (a) {
			{
				$\displaystyle
				L_{{\color{nmlred}q}}({\color{nmlcyan}Y}, {\color{nmlpurple}\hat{Y}}) = 
                \begin{cases} 
                    {\color{nmlred}q} \cdot ({\color{nmlcyan}Y} - {\color{nmlpurple}\hat{Y}}), & \text{if } {\color{nmlcyan}Y} \geq {\color{nmlpurple}\hat{Y}}, \\[10pt]
                    (1 - {\color{nmlred}q}) \cdot ({\color{nmlpurple}\hat{Y}} - {\color{nmlcyan}Y}), & \text{if } {\color{nmlcyan}Y} < {\color{nmlpurple}\hat{Y}}
                \end{cases}
                $
			}
		};
		% Adjusted arrows
		\draw[overlay,-latex,nmlred, semithick] ($(a.south)+(-4.25,0.65)$) to[bend right=29] node[pos=1, right] {quantile} +(0.55,-0.80);
		\draw[overlay,-latex,nmlcyan, semithick] ($(a.north)+(-3.80,-0.70)$) to[bend right=20] node[pos=1, left,align=center] {actual\\value} +(-0.75,0.50);
		\draw[overlay,-latex,nmlpurple, semithick] ($(a.south)+(0.50,0.20)$) to[bend right=29] node[pos=1, right] {predicted value} +(0.45,-0.35); 
	}
\end{center}

The loss is nonnegative and has no upper bound. At $q=0.9$, an under-prediction receives nine times the penalty of an equally large over-prediction. At $q=0.5$, the penalties match; averaging this loss gives half the MAE and targets the median.

\textbf{When to use Pinball Loss?}

Use it when evaluating a chosen quantile, such as an upper demand forecast for inventory planning or a lower and upper bound for a prediction interval. Choose the quantile to match the question: estimating a $90$th percentile and estimating a mean are different tasks.

\coloredboxes{
    \item The asymmetry can represent per-unit costs. If each unit of shortage costs nine times as much as each unit of surplus, $q=0.9$ matches that ratio.
    \item Scoring several quantiles, such as $0.1$, $0.5$, and $0.9$, helps assess the lower tail, center, and upper tail of a forecast.
}
{
    \item You must specify which quantile a prediction represents. A model trained for mean squared error generally targets the mean, not the chosen quantile.
    \item A few quantiles do not describe the whole distribution. Their coverage on new data also needs checking; a low loss does not guarantee exact coverage.
}

\thispagestyle{customstyle}

\begin{center}
    \includegraphics[width=\textwidth]{figures/Pinball_Loss.png}
\end{center}

\textbf{Figure. Pinball Loss.} Each curve shows the loss for one prediction against its residual, $Y-\hat{Y}$. Under-predictions lie on the right and incur $q$ per unit of error; over-predictions lie on the left and incur $1-q$ per unit of error. At $q=0.9$, the heavier penalty for under-prediction favors a higher forecast, targeting the $90$th percentile. This aims for about $10\%$ of outcomes above it, but does not guarantee that fraction in a finite test sample. At $q=0.5$, both sides equal half the absolute error.

\orangebox{Did you know that...}
{Pinball Loss is also called Quantile Loss or Check Loss. Roger Koenker and Gilbert Bassett used this asymmetric absolute-error objective in their 1978 paper \textit{Regression Quantiles}, extending regression beyond the mean to different quantiles of an outcome.}

\textbf{Other related metrics}

MAE targets the median, just as Pinball Loss does at $q=0.5$; MSE targets the mean. For a prediction interval, evaluate its lower and upper quantiles and check how often new outcomes fall inside it.

\clearpage
\thispagestyle{regressionstyle}
\section{Explained Variance Score}\label{sec:explained-variance-score}
\subsection{Explained Variance Score}

Explained Variance Score compares the variation in prediction errors with the variation in the targets, while ignoring the errors' average offset. For example, predictions $[8,9,10,11]$ for targets $[1,2,3,4]$ are always $7$ too high. Their errors have no variation, so EVS is $1$, even though $R^2=-38.2$. A perfect EVS therefore does not mean perfect predictions.

% formula
\begin{center}
    \tikz{
        \node[inner sep=2pt, font=\Large] (a) {
            {
                $\displaystyle
                \text{EVS} = 1 - \frac{\text{Var}({\color{nmlcyan}Y} - {\color{nmlpurple}\hat{Y}})}{\text{Var}({\color{nmlcyan}Y})}
                $
            }
        };
        
        \draw[overlay,-latex,nmlcyan, semithick] ($(a.south)+(1.50,0.05)$) to[bend left=11] node[pos=1, left] {actual value} +(-1.10,-0.30);
        \draw[overlay,-latex,nmlpurple, semithick] ($(a.north)+(2.20,0.00)$) to[bend left=15] node[pos=1, right] {predicted value} +(1.00,0.50); 
    }
\end{center}

For nonconstant targets, EVS has a maximum of $1$ and no lower bound. It equals $R^2$ when the mean error is zero. Otherwise EVS is higher, with the gap reflecting the squared mean error relative to target variance.

\textbf{When to use Explained Variance Score?}

Use EVS alongside $R^2$ to check how much of the squared error comes from predictions being too high or too low on average. The gap between the scores measures this contribution relative to the variation in the targets. Inspect errors within groups too, since over-prediction in one group can cancel under-prediction in another.

\coloredboxes{
    \item Comparing EVS with $R^2$ separates the contribution of the overall mean error from the variation around it.
    \item Adding a constant to every prediction leaves EVS unchanged. This helps isolate error variation when comparing otherwise identical predictions with different offsets.
}
{
    \item EVS ignores errors that matter in practice. Predictions $\hat{Y}=Y+1000$ score $1$ even though every prediction is wrong by $1000$.
    \item A zero overall mean error can hide over-prediction in one group and under-prediction in another. Neither EVS nor its gap from $R^2$ detects that by itself.
}

\thispagestyle{customstyle}

\begin{figure*}[ht!]
    \centering
    \includegraphics[width=\textwidth]{figures/EVS_vs_R2_three_models.png}
\end{figure*}

\textbf{Figure. Explained Variance Score.} All three models predict the same targets; the diagonal marks perfect predictions. On the left, a small mean error makes EVS and $R^2$ both round to $0.96$. The center model has a similar spread of errors but predicts about $6.2$ too high on average: EVS still rounds to $0.96$, while $R^2$ is $-0.22$. On the right, larger error variation brings both scores to about $0.21$.

\orangebox{Did you know that...}
{We can remove the average offset in a set of predictions by adding the mean error, $\operatorname{mean}(Y-\hat{Y})$, to each one. If predictions are $7$ too high on average, this subtracts $7$. EVS stays the same, while $R^2$ rises to match it on those data. The relationship is $EVS=R^2+\operatorname{mean}(Y-\hat{Y})^2/\operatorname{Var}(Y)$ for nonconstant targets.}

\textbf{Other related metrics}

To test whether an offset correction helps on new data, estimate it from one labeled dataset and evaluate the corrected predictions on another. Report $R^2$ with MAE or RMSE so readers can see both the relative improvement and the remaining error in the target's units. Check individual groups as well, because the same correction may help some and hurt others.
