\section{Who this is for}

This book is for data scientists, ML engineers and anyone building, improving or monitoring machine learning models. We assume
you know what a confusion matrix and a residual are, and not much more than that.

\section{How to read a metric page}

Almost every metric follows the same layout.

The first page defines the metric. It says what the metric measures, shows the formula with every symbol labeled, explains how to
read the value, tells you when to use it and when to avoid it, and lists its strengths and weaknesses side by side.

The second page shows the metric at work. A figure built from data walks through how the metric turns predictions into a score, a
``Did you know'' box gives one fact worth remembering, and a short note points to related metrics.

\section{Formula colors}

Formulas use five colors:

\begin{itemize}[left=0pt]
    \item {\color{nmlcyan}\textbf{Cyan}} for the truth: targets, labels, actual values.
    \item {\color{nmlpurple}\textbf{Purple}} for what the model produced: predictions, scores, estimates.
    \item {\color{nmlred}\textbf{Red}} for counts and sizes: samples, classes, bins, items.
    \item {\color{nmlgreen}\textbf{Green}} for special functions, like the indicator $\mathds{1}[\cdot]$.
    \item {\color{nmlyellow}\textbf{Yellow}} for what you choose: thresholds, weights, quantile levels.
\end{itemize}

\section{How the book is organized}

Chapters follow the kind of model being evaluated: regression, classification, clustering, ranking, computer vision, NLP and
generative AI. The last three chapters cover estimating performance before the labels arrive, fairness across groups, and monitoring
the data that feeds the models. Each chapter opens with a one-page guide to choosing among its metrics, and every figure is
generated by code in the book's repository, from the data it shows.
